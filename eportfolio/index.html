01 / Electric mobility / Team leadership

Digital dashboard & live telemetry

As group leader during my June/July vacation work at UCT, I worked with a team on a digital dashboard for an electric tuk-tuk and a web interface for live telemetry.

Embedded UI · Telemetry · Teamwork

Project notes +

My contribution

Group leadership and hands-on development of the vehicle display and web telemetry interface. The project connected an embedded user interface with the information needed to understand vehicle operation.

02 / Radar / Final-year project

Making sense of a golf swing

I’m developing a low-cost radar system to analyse golf swings, with a focus on signal processing, accuracy and affordability.

MATLAB · CW radar · Signal processing

Project notes +

Current work

My MATLAB pipeline turns recorded continuous-wave radar signals into speed–time spectrograms. I’m investigating CFAR detection, clustering and reduced markers to describe the swing’s motion. This is ongoing research; performance is still being evaluated.

03 / Wireless systems / Design project

Project Icicle

A communications subsystem for an Antarctic buoy, combining Bluetooth and LoRa transmission with a web dashboard for telemetry and GPS locations.

Bluetooth · LoRa · Telemetry

Project notes +

My contribution

I developed the communications subsystem as part of my fourth-year design project, working across wireless data transmission and the interface used to view the buoy’s telemetry.

04 / Embedded programming / 2024

A functional Snake game emulator built using the ESP8266, bringing game logic and real-time interaction onto an embedded platform.

ESP8266 · Embedded systems · Game logic

02 / About me

A practical mind.
A curious outlook.

I’m interested in what happens when a signal becomes useful information, and when software starts interacting with the physical world.

At UCT, I’m completing my final year in Electrical and Computer Engineering. My interests span embedded systems, RF and electromagnetics, and control systems, with current project work focused on radar signal processing.

Alongside my studies, I tutor university courses and enjoy helping students work through technical problems. Outside engineering, you’ll find me on the golf course with the UCT Golf Club.
